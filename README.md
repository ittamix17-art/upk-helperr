# 🎓 УПК: Цифровой помощник колледжа

> **Единая цифровая среда для обработки заявок и обращений**
> Решает проблему потери информации, дублирования заявок и долгого ожидания ответа от сотрудников.

## 🚀 Что умеет система (Функционал)

### 1. Умный ИИ-помощник (Гибридный)
Система анализирует текст пользователя и разделяет его на категории:
- **Типовой вопрос** (например, «Как подключить проектор?») — выдает пошаговую инструкцию из локальной базы знаний, **указывая источник**.
- **Неисправность** (например, «Сломался стул») — предлагает категорию, черновик заявки и рекомендует её оформить.
- **Потенциальная опасность** (искрит розетка, дым, пожар) — **блокирует** возможность дачи опасных советов по ремонту, требует обесточить помещение и дает кнопку вызова экстренных служб (112/104). 
- **Нестандартный вопрос** — подключает внешнюю языковую модель (LLM) через API `Pollinations.AI`. Модель работает без API-ключей в клиентском коде (безопасно).
- **Честная неопределённость** — если ИИ не уверен в ответе, он прямо об этом сообщает и предлагает обратиться к сотруднику.

### 2. Работа с заявками
- **Подача через QR-код**: сканируя код в кабинете, пользователь попадает на форму, где помещение подставляется автоматически (механизм `?qr=214`).
- **Защита от дубликатов**: система проверяет, не отправлял ли пользователь такую же заявку в последние 5 минут.
- **Фотографии**: до 10 штук. Встроенный `TensorFlow.js` (MobileNet) автоматически **распознает объекты** на фото (например, "компьютерная клавиатура") и подсказывает категорию.
- **Умный приоритет**: система автоматически ставит высокий приоритет заявкам, связанным с электричеством, водой или опасностью.
- **Сквозной трекинг**: после отправки выдается уникальный номер (UPK-YYYY-XXXX) и безопасная ссылка с токеном для отслеживания статуса без авторизации.

### 3. Панель сотрудника (CRM)
- Поиск по номеру и тексту, фильтры по статусу, категории, помещению и **дате**.
- Управление жизненным циклом: `Новая → На рассмотрении → Назначен исполнитель → В работе → Решена / Отклонена`.
- **Валидация**: нельзя перевести заявку в статус «Решена» или «Отклонена» без обязательного итогового комментария.
- **История**: фиксируется каждое действие (кто, когда и что изменил).
- **Аналитика**: живой дашборд со статистикой (количество заявок, среднее время решения, распределение по категориям).
- **Экспорт в CSV**: одна кнопка для выгрузки всех заявок.

### 4. Доступность и удобство (A11y)
- **Версия для слабовидящих**: увеличение шрифта (до 5 уровней), выбор шрифта (с засечками/без), изменение цветовой схемы (высокий контраст, чёрно-жёлтая, чёрно-белая).
- **Синтез речи**: озвучка всего текста на странице и ответов ИИ через `Web Speech API`.
- **Тёмная и светлая тема**.
- **Мультиязычность**: Русский и Английский.

## ⚠️ Честные ограничения MVP (Согласно ТЗ)

1. **База данных**: В данной MVP-версии используется `LocalStorage`. Это значит, что заявки, созданные на одном устройстве, не синхронизируются с другим. В Production-версии мы перейдем на **PostgreSQL + FastAPI**.
2. **Пароли**: Для демонстрации пароли захардкожены и хешируются простым алгоритмом. В реальном проекте используется серверная авторизация (JWT) и надежное хеширование (bcrypt).
3. **ИИ**: Языковая модель (Pollinations.AI) может ошибаться. Поэтому логика построена так, что при низкой уверенности или потенциальной опасности диалог переводится на человека (сотрудника).

## 📦 Как запустить локально

1. Скачайте репозиторий.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Safari).
3. **Сервер не требуется!** Всё работает офлайн (кроме запросов к внешней LLM).
